# The-Sidon-Constant-of-n-Consecutive-Frequencies
For a finite subset $E\subset\mathbb Z$, its Fourier-analytic Sidon constant is the least $C$ such that

$$\sum_{k\in E}|a_k|\le C\sup_{|z|=1}\left|\sum_{k\in E}a_kz^k\right|\qquad(a_k\in\C).$$

We consider the initial segments $E=\{0,\ldots,n\}$, writing $S_n$ for this constant. To calculate $S_n$ is not easy, so we will first try to determine it for $n=5,6,7$, etc. Then, we will try to develop a strong method that allows us to study $S_n$ precisely.
